today we will learn about the context window.


A context window is the amount of information (in tokens) that a model like Claude Code can see and remember at one time while generating a response.
Think of it as the model's working memory.\

Context is all the information available to understand something correctly
context window is the maximum amount of context the model can hold at once.
claude code has a context window of 200k tokens,
each session get new fresh context window.
