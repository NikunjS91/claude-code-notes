with this agent we can profile tools system prompt and skills and make him work how we want him to do so.

when ever we need specialization then we have to work with sub-agents.


how to make one?

same markdown files.
---
name: code-reviewer
description: Reviews code for quality and best practices tools: Read, Glob, Grep 
model: sonnet
---
You are a code reviewer. When invoked, analyze the code and provide specific, actionable feedback on quality, security, and best practices.

these below can be set as well.
name
Unique ID, lowercase with hyphens
description
Tells Claude when to delegate to this agent
tools
Allowlist of tools (eg. Read, Grep, Glob, Bash). Inherits all if omitted
disallowedTools
Denylist - removes specific tools from the inherited set
model
sonnet, opus, haiku, a full model ID, or inherit (default)
permissionMode
default, acceptEdits, auto, dontAsk, bypassPermissions, or plan

maxTurns
Max agentic turns before it stops
skills
Skills to preload into the subagent's context
mcpServers
MCP servers scoped to this subagent
hooks
Lifecycle hooks (eg. PreToolUse, PostToolUse)
memory
Persistent memory scope: user , project,or local
background
true to always run in background
effortt
low, medium, high, xhigh, or max
isolation
Set to worktree for an isolated git worktree copy
color
Ul color: red, blue, green, yellow, purple, orange, pink, cyan
initialPrompt
Auto-submitted first user turn when run as main agent
